# Project Cute

A browser-based dress-up and idle game. Set a focus timer, earn gemstones and buy new clothes. No installation, no account — just open the link and play.

---

## Play

**Play online: [lalicka.github.io/Project_Cute_online](https://lalicka.github.io/Project_Cute_online/)**

Any modern browser works (Chrome, Firefox, Edge, Safari). The first launch asks for your name.

### Run it locally instead

If you'd rather have an offline copy:

1. Click the green **Code** button at the top of this page, then choose **Download ZIP**.
2. Extract the ZIP somewhere on your computer.
3. Double-click `index.html` inside the extracted folder.

(Or, if you already use Git: `git clone <repo-url>`.)

It runs straight from the file — no server, no internet connection needed after the download.

---

## Saving your progress

Saves happen **automatically**. Whatever you buy, equip, or arrange is stored by your browser, so the next time you visit the page (or open `index.html`) everything is right where you left it.

A few things to know:

- Saves are tied to your browser, so a different browser or another computer starts fresh.
- The online version and a local copy you downloaded keep **separate** saves — they live at different addresses, so the browser treats them as different games. Use Export / Import (below) to move a save between them.
- Clearing your browser's site data will erase the save.
- The timer and music position are **not** saved — they reset on reload. Currency, owned items, and equipped outfits are.

### Backing up or moving a save

Click the save icon next to your name at the top of the left panel to open the Import / Export menu.

- **Export** downloads your current save as a small `player.js` file. Keep it as a backup, or send it to yourself to use elsewhere.
- **Import** loads a `player.js` file back into the game. The page reloads and your save is restored.

This is how you transfer progress to a different browser or computer.
